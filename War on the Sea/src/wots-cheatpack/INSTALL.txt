War on the Sea Cheat Pack - Self-Contained Pack
===============================================
This pack bundles BepInEx 5.4.23.2 (x64) plus all four mods, so there is no
separate BepInEx install to get wrong. It targets the x64 Mono build of
War on the Sea v1.09a.

INSTALL
-------
1. Extract this zip INTO the game folder (the folder that contains
   WarOnTheSea.exe). It drops winhttp.dll, doorstop_config.ini and a
   BepInEx\ folder next to the executable.
2. Launch WarOnTheSea.exe.
3. Default hotkeys:

     F1  Infinite Command Points     (Trainer, campaign)
     F2  Reveal All                  (Trainer, campaign + battles)
     F5  Ace Aviators on/off         (air strikes)
     F6  Ace Aviators mode           (AimOnly / AimAndGuidance)
     F7  More Targets on/off         (campaign, enemy AI budget)
     F8  Fire Control on/off         (AA + naval gunnery)

   All of these are defaults. Each mod writes its own file into
   BepInEx\config\ on first run and reads its hotkeys from there, so
   rebind anything that clashes with your setup.

REMOVE
------
Delete the three items you just added: winhttp.dll, doorstop_config.ini,
and the BepInEx\ folder. Nothing existing is touched.

INSTALLING ONLY SOME OF THEM
----------------------------
The four plugins are independent. Delete any you do not want from
BepInEx\plugins and the rest carry on:

  WoTSTrainer.dll        command points, fog of war
  WoTSAceAviators.dll    air strike accuracy
  WoTSMoreTargets.dll    enemy campaign AI budget
  WoTSFireControl.dll    AA accuracy, gunnery fire solution

NOTES
-----
- First launch of BepInEx may take a few seconds longer while it builds its
  config folder. The plugin log is at game\BepInEx\LogOutput.log.
- Everything is player-side. No mod here improves enemy aim, enemy AA or enemy
  fire control. More Targets is the only one that changes anything on the
  enemy's side, and all it does is stop their treasury running dry.
- No mod writes anything to a save. A save made with all four installed still
  loads with none of them.
- Campaign-only cheats (F1, F2 campaign map, F7) do nothing in skirmish.
- docs\ has each mod's own README, including the measurements behind the
  defaults and what each one deliberately does NOT do.
