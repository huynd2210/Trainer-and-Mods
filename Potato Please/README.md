# Potato Please mods

Two BepInEx 6 IL2CPP mods. Each one works alone; install either or both.

| Mod | What it does |
| --- | --- |
| **Steady Hands** | Your hands stop shaking while you peel: no hand tremor, no hand drift, no out-of-stamina shake. Each one can be switched back on. |
| **Starting Cash** | Press F8 in a game to get ₽10,000. The key and the amount can be changed. |

## Install

1. Install BepInEx 6 IL2CPP x64 into the game folder (be.781 tested, from builds.bepinex.dev) and start
   the game once. See `dist\LOADER-NOT-BUNDLED.md`.
2. Extract `dist\SteadyHands.zip` and/or `dist\StartingCash.zip` into the game folder.

Settings are in `BepInEx\config\dev.potatoplease.*.cfg` after the first launch. Details for each mod are
in `src\<Mod>\README.md`.

## Requirements

Potato Please (Unity 6000.3, IL2CPP, win-x64) with BepInEx 6.0.0-be.781 IL2CPP x64.
