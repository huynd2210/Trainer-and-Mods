# Unlimited Slots (Sushiamo mod)

Hold as many tools and sauces as you like. Buying, rewards and events never fail with "no space".

The shelf counters keep showing your **normal capacity** (e.g. `7/5` = 7 tools held, 5 normal slots),
because some items still care about it:

- **Zen Garden** counts empty slots of the normal capacity; holding more than that leaves none.
- **Sake** and the **fill sauce slots** reward fill the normal capacity's empty slots.
- **Fukubukuro** gives its tool only while you hold fewer tools than the normal capacity.
- **+1 slot** rewards and **boss rerolls** still raise or lower the normal capacity. Losing a slot to a
  reroll no longer destroys a tool.

The shelves fan the cards out when they fill up, as the game already does.

## Install

Copy the mod's zip into `<game folder>\mods\` and start the game. The game has a mod
loader built in; no other install is needed. It works on new and existing runs.

To turn it off, remove the zip. A run saved while the mod was on keeps unlimited slots (its counters will
read e.g. `7/105`); new runs are normal.
