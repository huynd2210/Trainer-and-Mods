# Precision Pipettes

Two smaller droppers for doses under a millilitre:

| Dropper | Holds | Bulb | Price |
|---|---|---|---|
| 0.5 ml | 0.5 ml | green | 150 |
| 0.1 ml | 0.1 ml | red | 200 |

The vanilla 1 ml dropper has a teal bulb and the 5 ml a purple one, so all four are easy to
tell apart in a drawer. They work exactly like the vanilla droppers: use an empty one on a
container to draw, use a full one on a container to drop all of it. The tooltip shows the
volume to the thousandth of a ml (the vanilla one rounds to whole ml, which would show
0.5 ml as "1 ml").

**Where to get them:** the Retired Chemist puts both on the table whenever they offer the
1 ml dropper (half of their visits).

The green and red sprites are made in the game from its own 1 ml dropper sprite, so no game
art ships with the mod.

**Before removing the mod**, sell or trash these droppers: a save that still holds one
loads it as a blank placeholder item.

## Install

1. Extract the zip into the game folder (the one with `Probably Stolen.exe`), so you get
   `Mods\PrecisionPipettes\PrecisionPipettes.dll` and `manifest.xml`.
2. Start the game, open **Mods** from the main menu, enable **Precision Pipettes**, restart.

Uses the game's built-in mod loader and needs no other mod. Made for v0.46D.
