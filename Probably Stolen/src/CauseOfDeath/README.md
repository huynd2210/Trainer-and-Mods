# Cause of Death

Dead fish and rats say why they died. Hover a carcass: the game's red `[Dead]` tag becomes
e.g. `[Dead: starved]`, `[Dead: unpowered tank, polluted water]`, `[Dead: mauled by a bigger cagemate]`.

Fish: old age, starved, suffocated outside a tank, unpowered tank, not enough / low water,
toxic / polluted water, killed with a blade, auto-butcher.
Rats: old age, starved, disease, weak immunity, mauled by a bigger cagemate (overcrowding),
killed with a blade, auto-butcher.

The cause is saved on the carcass. Animals that died before you enabled the mod just show `[Dead]`.

## Install

1. Extract the zip into the game folder, so you get `Mods\CauseOfDeath\CauseOfDeath.dll` and `manifest.xml`.
2. Start the game, open **Mods** from the main menu, enable **Cause of Death**, restart.

Uses the game's built-in mod loader. Made for v0.46D.
