# Unlimited Reputation

Faction reputation no longer stops at 200. It keeps climbing for as long as you keep
earning it, and everything in the game that scales with reputation (haggling odds,
supplier and rare-item chances, black market stock, tips) keeps scaling with it.

- The reputation panel shows your real number (no more `/200`); past 200 the bar stays
  full and the status stays at the top tier.
- Losing reputation still bottoms out at -200, as before.

## Install

1. Extract the zip into the game folder (the one with `Probably Stolen.exe`), so you get
   `Mods\UnlimitedReputation\UnlimitedReputation.dll` and `manifest.xml`.
2. Start the game, open **Mods** from the main menu, enable **Unlimited Reputation**, restart.

Uses the game's built-in mod loader; nothing else is needed. Made for v0.46D.
