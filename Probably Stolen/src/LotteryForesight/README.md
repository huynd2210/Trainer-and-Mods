# Lottery Foresight

Know before you buy.

- **Lottery tickets:** hover one to see the numbers the coming draw will pick (yours in
  green) and what the ticket wins, e.g. `Wins 300 credits (3 of 6)` or
  `No prize (1 of 6)`.
- **Scratch tickets:** hover one to see its prize before scratching, e.g.
  `Scratch prize: 75 credits`.

Works on tickets on a seller's table too, so you can buy only the winners.

The game normally draws the weekly numbers at random on draw night, so there is nothing
to read in advance. This mod fixes each week's numbers ahead of time (from your store's
name and the draw number, so they survive saving and reloading) and the real draw uses
them. That replaces the game's luck-based re-draws for the lottery. Scratch tickets are
untouched: their symbols are printed when the ticket is made. If your luck rises before
you scratch, the game may re-print a ticket in your favour, and the tooltip follows.

## Install

1. Extract the zip into the game folder (the one with `Probably Stolen.exe`), so you get
   `Mods\LotteryForesight\LotteryForesight.dll` and `manifest.xml`.
2. Start the game, open **Mods** from the main menu, enable **Lottery Foresight**, restart.

Uses the game's built-in mod loader; nothing else is needed. Made for v0.46D.
