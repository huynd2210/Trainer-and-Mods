# No Rent Increase

The landlord stops raising the rent. Your weekly rent stays at whatever it is when
you turn the mod on, whether you pay or miss a week. Rent changes you agree to
yourself (the vending machine deals, starting perks) still apply.

## Install

1. Extract the zip into the game folder (the one with `Probably Stolen.exe`), so you get
   `Mods\NoRentIncrease\NoRentIncrease.dll` and `manifest.xml`.
2. Start the game, open **Mods** from the main menu, enable **No Rent Increase**, restart.

Uses the game's built-in mod loader; nothing else is needed. Made for v0.46D.
