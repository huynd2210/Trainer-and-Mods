# Recursive Storage

Storage bays fit inside other storage bays, as deep as you like: a storage bay inside a
large storage bay, a makeshift bay inside that, and so on. Drag a bay into another bay's
window like any other item; open it from there as usual.

- Works with the makeshift, normal and large storage bays, the machine bays and the
  hypertech bay, both as the outer and the inner bay. Smuggler bays can go inside them too.
- The gunsmith and chemist bays still take only their own goods, smuggler bays keep
  their own rules, and backpacks still stay out.
- A bay can't go inside itself or inside a bay it already holds.

## Install

1. Extract the zip into the game folder (the one with `Probably Stolen.exe`), so you get
   `Mods\RecursiveStorage\RecursiveStorage.dll` and `manifest.xml`.
2. Start the game, open **Mods** from the main menu, enable **Recursive Storage**, restart.

Before disabling the mod, take nested bays back out: the game won't let you put them
back in without it. Uses the game's built-in mod loader; nothing else is needed. Made for
v0.46D.
