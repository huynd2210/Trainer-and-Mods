# Auto Appraisal

Appraisal jobs, done right every time. You still press **Estimate** yourself, so the
game's own dialogue, payment and reputation work as normal.

- **Hover an appraisal item** to see `True value: N`.
- **Inspect it** and the estimate box already holds that exact number.
- **Turn it off mid-run** under **Options > Game Settings > Auto Appraisal**, then Apply.
  Takes effect at once, no restart; the choice is remembered.

To catch counterfeits and hidden conditions, see the separate **Fraud Detection** mod.

## Install

1. Extract the zip into the game folder (the one with `Probably Stolen.exe`), so you get
   `Mods\AutoAppraisal\AutoAppraisal.dll` and `manifest.xml`.
2. Start the game, open **Mods** from the main menu, enable **Auto Appraisal**, restart.

Uses the game's built-in mod loader; nothing else is needed. Made for v0.46D.
