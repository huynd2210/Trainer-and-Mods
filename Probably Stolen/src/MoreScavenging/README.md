# More Scavenging

Adds extra scavenging attempts at the dumping ground every night: **1000** by default.
Change it (0 to 10000) in this mod's settings in the Mods menu.

The game raises the injury chance with every attempt (+1% minor, +0.25% major), so by a
few dozen attempts an injury is near-certain, and a fresh wound ends scavenging for the
night. With **Keep injury risk normal** on (the default), the chance stops rising after
your normal attempts and stays at the level of your last normal attempt. The percentages
shown at the dumping ground reflect it. Turn it off for the vanilla curve.

Everything you find still goes into your after-hours inventory, so make room.

## Install

1. Extract the zip into the game folder (the one with `Probably Stolen.exe`), so you get
   `Mods\MoreScavenging\MoreScavenging.dll` and `manifest.xml`.
2. Start the game, open **Mods** from the main menu, enable **More Scavenging**, restart.

Uses the game's built-in mod loader; nothing else is needed. Made for v0.46D.
