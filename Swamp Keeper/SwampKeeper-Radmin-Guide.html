Swamp Keeper v1.05 · Online Co-op

Playing through Radmin VPN

Use Radmin VPN to put both PCs on the same virtual LAN, then connect the guest directly to the host's Radmin IP from the co-op menu.

No router port forwarding is needed when both players use Radmin VPN. The guest connects through Radmin's virtual network instead.

Before you start

  • Both players need the same Swamp Keeper version and the same co-op mod build.
  • Both PCs need Radmin VPN. Download it from radmin-vpn.com.
  • The co-op mod uses TCP port 27856.
  • Keep the game at the title screen until the host and guest have connected.

1. Create the Radmin network

1

Host

Open Radmin VPN and choose Create network.

2

Host

Choose a Network name and Password, then press Create.

3

Guest

Open Radmin VPN and choose Join network.

4

Guest

Enter the host's Radmin Network name and Password, then press Join.

The Radmin network password and the Swamp Keeper session code are two separate things. You will use both.

2. Find the host's Radmin IP

Once both players are in the same Radmin network, the host will appear in the network member list.

Copy the host's Radmin VPN IP address. It will normally look like:

26.x.x.x

Use this Radmin IP in Swamp Keeper. Do not use the host's normal home/LAN address such as 192.168.x.x.

Before opening the game, the guest can right-click the host in Radmin VPN and choose Ping. A successful ping is a good sign that the virtual LAN is working.

3. Start the Swamp Keeper co-op session

Host Guest
Launch Swamp Keeper and stay on the title screen. Launch Swamp Keeper and stay on the title screen.
Press F7 to open ONLINE CO-OP. Press F7 to open ONLINE CO-OP.
Create/copy the Session Code and click Host. Enter the same Session Code.
Send the guest your Radmin IP and Session Code. Enter the host's Radmin IP (26.x.x.x) as the host address.
Wait for the guest to connect. Click Join.

4. Choose items and skills

  1. Each player opens the co-op menu with F7.
  2. Choose your own items and your two skills.
  3. Each player presses Ready.
  4. Once both players are ready, the host enters the run normally.

The host and guest have separate loadouts and separate player characters. The host controls run progression.

What information do I send my friend?

Radmin network name Used to join the same virtual LAN.
Radmin network password Used only by Radmin VPN.
Host Radmin IP Usually 26.x.x.x. Guest enters this in the Swamp Keeper co-op menu.
Swamp Keeper Session Code Both players must use the same code for the co-op session.

Troubleshooting

Guest cannot connect

  1. Confirm both PCs appear in the same Radmin VPN network.
  2. From the guest PC, right-click the host in Radmin and run Ping.
  3. Confirm the guest entered the host's Radmin IP, usually 26.x.x.x.
  4. Confirm both players entered the exact same Swamp Keeper Session Code.
  5. Confirm both players have the same game/mod version.
  6. Allow Swamp Keeper and/or TCP 27856 through Windows Firewall on the host.

Radmin Ping fails

Fix the Radmin connection first. If Radmin itself cannot reach the host, Swamp Keeper will not be able to connect through it either.

The game says the session code is wrong

The Radmin password does not replace the game's Session Code. Copy the code shown in the F7 ONLINE CO-OP menu exactly.

Windows Firewall prompt appears

Allow Swamp Keeper network access. If it was previously denied, open Windows Security → Firewall & network protection → Allow an app through firewall and allow Swamp Keeper.

Do I need to forward port 27856 on my router?

No. When using Radmin VPN, both PCs communicate through the Radmin virtual LAN. Router port forwarding is unnecessary.

Fast checklist

  1. Both install Radmin VPN.
  2. Host: Create network.
  3. Guest: Join network.
  4. Guest pings host successfully in Radmin.
  5. Host sends guest the host's 26.x.x.x Radmin IP.
  6. Both launch Swamp Keeper and stay at the title screen.
  7. Both press F7.
  8. Host clicks Host; guest enters host Radmin IP and clicks Join.
  9. Both choose loadouts and press Ready.
  10. Host starts the run.
Radmin VPN terminology checked against the official Radmin VPN help page. Swamp Keeper co-op default port: TCP 27856.
