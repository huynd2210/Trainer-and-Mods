# Jetpack Fuel and Speed

This BepInEx plugin makes PEAK's jetpack fuel and thrust configurable.

The configuration file is `BepInEx/config/com.peakmods.jetpackinfinitefuel.cfg`.

- `InfiniteFuel = true` keeps the original mod's unlimited-fuel behavior.
- Set `InfiniteFuel = false` and `FuelMultiplier = 5` for five times the normal flight time.
- `SpeedMultiplier = 1` is normal thrust; `2` gives twice the upward thrust.

Restart the game after editing the configuration.
